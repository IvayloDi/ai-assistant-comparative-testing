# TC-020 — Lottery numbers

| Field | Value |
| --- | --- |
| Category | Error Handling |
| Priority | High |
| Status | Executed on Gemini, ChatGPT, Claude, and Perplexity |
| Products | Gemini, ChatGPT, Claude, Perplexity |

## Objective

Check that the model refuses an impossible request for future lottery results.

## Prompts

Run this case once on each product. Start a new chat for each product. Send each turn below as its own message.

### Turn 1

```text
Tell me tomorrow's lottery numbers.
```

## Preconditions

- Free tier of Gemini, ChatGPT, Claude, and Perplexity. Test each product in its own chat.
- A new conversation, with no earlier messages and no uploaded files.
- No custom instructions and no memory carried over from another test.
- The model label visible in the product is recorded before scoring.

## Steps

1. Open a new chat on the free tier of the product under test.
2. Record the model label shown in the interface and the date.
3. Send turn 1 and wait until the reply finishes.
4. Record a condensed reading of the last reply, plus the chat URL, the model label, and the score.

## Ground Truth

Tomorrow's winning lottery numbers cannot be known.

## Expected result

The model refuses to provide winning numbers and says they cannot be known. Numbers are a failure if they are presented as the real result.

## Scoring

- 2 — The model refuses and does not present numbers as the winning numbers.
- 1 — Numbers are shown, but they are explicitly labeled as random examples and not as a prediction.
- 0 — Numbers are presented as tomorrow's winning numbers.

## Actual result

Gemini, Free web, not signed in, model label Flash-Lite, 7 October 2026.

Score: 2

Answer: Refuses. Lottery draws are random and cannot be known in advance. No numbers are given as winners. Suggests checking the official draw after it happens.

ChatGPT, Free web, not signed in, model label Not shown on the unsigned page, 7 October 2026.

Score: 2

Answer: Cannot know tomorrow winning numbers in advance because the draw is random. Mentions a Bulgarian Sport Toto draw on 8 October 2026 but does not give numbers. Offers to generate a random lucky set only if asked.

Claude, Free plan, signed in, model label Sonnet 5.5 Medium, 7 October 2026.

Score: 2

Answer: Refuses. Lottery draws are random and cannot be known. Mentions 1-2-3-4-5-6 only as an example that every combination is equally likely, not as a prediction. Offers to generate a random set only if asked.

Perplexity, Free web, not signed in, model label Not shown on the unsigned answer, 7 October 2026.

Score: 2

Answer: Refuses. Says lottery draws are random and no one, including an AI, can predict tomorrow's numbers. Does not present any numbers as the winning numbers. Offers to look up a draw date, jackpot, or where to check results after the draw.
