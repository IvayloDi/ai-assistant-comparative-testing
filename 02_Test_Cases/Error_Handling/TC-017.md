# TC-017 — Contradictory length

| Field | Value |
| --- | --- |
| Category | Error Handling |
| Priority | High |
| Status | Executed on Gemini, ChatGPT, Claude, and Perplexity |
| Products | Gemini, ChatGPT, Claude, Perplexity |

## Objective

Check that the model notices two constraints that cannot both be true.

## Prompts

Run this case once on each product. Start a new chat for each product. Send each turn below as its own message.

### Turn 1

```text
Write a text that is exactly 100 words and exactly 50 words.
```

## Preconditions

- Free tier of Gemini, ChatGPT, Claude, and Perplexity. Test each product in its own chat.
- A new conversation, with no earlier messages and no uploaded files.
- No custom instructions and no memory carried over from another test.
- The model label visible in the product is recorded before scoring.

## Steps

1. Open a new chat on the free tier of the product under test.
2. Record the model label shown in the interface and the date.
3. Send turn 1 and wait until the reply finishes.
4. Record a condensed reading of the last reply, plus the chat URL, the model label, and the score.

## Ground Truth

The two length constraints contradict each other.

## Expected result

The model says one text cannot be both exactly 100 words and exactly 50 words. It does not claim that a single text satisfies both constraints.

## Scoring

- 2 — The contradiction is stated explicitly, and no text is claimed to meet both lengths.
- 1 — The model notices the conflict, but still produces one text without a clear statement that both lengths are impossible together.
- 0 — A text is presented as both exactly 100 words and exactly 50 words, or the conflict is ignored.

## Actual result

Gemini, Free web, not signed in, model label Flash-Lite, 7 October 2026.

Score: 2

Answer: A single text cannot be both 100 and 50 words at the same time. Gemini then offers a separate 50-word text and a separate 100-word text. It does not claim one text meets both lengths.

ChatGPT, Free web, not signed in, model label Not shown on the unsigned page, 7 October 2026.

Score: 2

Answer: Those requirements conflict: a single text cannot be exactly 100 words and exactly 50 words at the same time. Offers to write one or the other. Does not claim one text meets both.

Claude, Free plan, signed in, model label Sonnet 5.5 Medium, 7 October 2026.

Score: 2

Answer: States that no text can be both exactly 100 words and exactly 50 words. Then offers a different reading: 100 words made of 50 distinct words, and writes that text. It does not claim one text meets both length constraints.

Perplexity, Free web, not signed in, model label Not shown on the unsigned answer, 7 October 2026.

Score: 2

Answer: States that two different word totals cannot both be satisfied by one passage. Writes a passage it says contains exactly fifty words, not one hundred, and says a text cannot simultaneously contain two different word totals.
