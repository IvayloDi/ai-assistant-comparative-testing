# TC-016 — Ambiguous Java

| Field | Value |
| --- | --- |
| Category | Error Handling |
| Priority | Medium |
| Status | Executed on Gemini, ChatGPT, Claude, and Perplexity |
| Products | Gemini, ChatGPT, Claude, Perplexity |

## Objective

Check how the model handles a question with several common meanings.

## Prompts

Run this case once on each product. Start a new chat for each product. Send each turn below as its own message.

### Turn 1

```text
Tell me about Java.
```

## Preconditions

- Free tier of Gemini, ChatGPT, Claude, and Perplexity. Test each product in its own chat.
- A new conversation, with no earlier messages and no uploaded files.
- No custom instructions and no memory carried over from another test.
- The model label visible in the product is recorded before scoring.

## Steps

1. Open a new chat on the free tier of the product under test.
2. Record the model label shown in the interface and the date.
3. Send turn 1 and wait until the reply finishes.
4. Record a condensed reading of the last reply, plus the chat URL, the model label, and the score.

## Ground Truth

Java can mean the programming language, the island, or the coffee. The model should show that it noticed the ambiguity.

## Expected result

The model asks which meaning is intended, or names more than one meaning before answering.

## Scoring

- 2 — The model asks which Java is meant, or lists the main meanings before choosing one.
- 1 — The model answers one meaning and briefly notes that another meaning exists.
- 0 — One meaning is presented as the only meaning, with no signal that the question is ambiguous.

## Actual result

Gemini, Free web, not signed in, model label Flash-Lite, 7 October 2026.

Score: 0

Answer: Model label Flash-Lite. Presents Java only as the programming language, first released in 1995 by Sun Microsystems, with the JVM. Does not mention the island or coffee. The closing question asks about learning Java for software development or its history, not which meaning is intended.

ChatGPT, Free web, not signed in, model label Not shown on the unsigned page, 7 October 2026.

Score: 0

Answer: Presents Java only as the programming language. Mentions JavaScript as a different language. Does not mention the island or coffee and does not ask which meaning is intended.

Claude, Free plan, signed in, model label Sonnet 5.5 Medium, 7 October 2026.

Score: 2

Answer: Lists three meanings before going deep on one: the programming language, the Indonesian island, and coffee. Asks which meaning the user wants.

Perplexity, Free web, not signed in, model label Not shown on the unsigned answer, 7 October 2026.

Score: 0

Answer: Describes Java only as the programming language and platform. Distinguishes JavaScript. Does not mention the island or coffee, and does not ask which meaning is intended.
