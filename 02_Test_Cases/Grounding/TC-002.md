# TC-002 — Microsoft headquarters

| Field | Value |
| --- | --- |
| Category | Grounding |
| Priority | High |
| Status | Executed on Gemini, ChatGPT, Claude, and Perplexity |
| Products | Gemini, ChatGPT, Claude, Perplexity |

## Objective

Check that the model locates a well-known company headquarters correctly.

## Prompts

Run this case once on each product. Start a new chat for each product. Send each turn below as its own message.

### Turn 1

```text
Where is the headquarters of Microsoft?
```

## Preconditions

- Free tier of Gemini, ChatGPT, Claude, and Perplexity. Test each product in its own chat.
- A new conversation, with no earlier messages and no uploaded files.
- No custom instructions and no memory carried over from another test.
- The model label visible in the product is recorded before scoring.

## Steps

1. Open a new chat on the free tier of the product under test.
2. Record the model label shown in the interface and the date.
3. Send turn 1 and wait until the reply finishes.
4. Record a condensed reading of the last reply, plus the chat URL, the model label, and the score.

## Ground Truth

Microsoft's corporate headquarters is in Redmond, Washington, United States.

## Expected result

The answer identifies Redmond, Washington as the headquarters. Naming One Microsoft Way is optional and is not required for a pass.

## Scoring

- 2 — Redmond, Washington (or Redmond, WA) is given as the headquarters.
- 1 — The answer says the Seattle area or Washington state, but does not name Redmond.
- 0 — A different city is given as the headquarters.
