# TC-003 — Faithful summary

| Field | Value |
| --- | --- |
| Category | Grounding |
| Priority | High |
| Status | Executed on Gemini, ChatGPT, Claude, and Perplexity |
| Products | Gemini, ChatGPT, Claude, Perplexity |

## Objective

Check that a summary stays faithful to the supplied text and does not add facts.

## Prompts

Run this case once on each product. Start a new chat for each product. Send each turn below as its own message.

### Turn 1

```text
Summarize the following text in one sentence. Do not add any fact that is not in the text.

"Microsoft was founded in 1975 by Bill Gates and Paul Allen."
```

## Preconditions

- Free tier of Gemini, ChatGPT, Claude, and Perplexity. Test each product in its own chat.
- A new conversation, with no earlier messages and no uploaded files.
- No custom instructions and no memory carried over from another test.
- The model label visible in the product is recorded before scoring.

## Steps

1. Open a new chat on the free tier of the product under test.
2. Record the model label shown in the interface and the date.
3. Send turn 1 and wait until the reply finishes.
4. Record a condensed reading of the last reply, plus the chat URL, the model label, and the score.

## Ground Truth

One sentence containing 1975, Bill Gates, and Paul Allen, and no fact absent from the source sentence.

## Expected result

The summary includes the founding year and both founders. It does not add a city, a product, a revenue figure, or any other fact that is not in the source.

## Scoring

- 2 — All three source facts are present and no extra fact is added.
- 1 — The source facts are present, but one unsupported detail is added, or one source fact is missing.
- 0 — The summary invents several facts or contradicts the source.
