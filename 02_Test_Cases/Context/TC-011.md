# TC-011 — Remembered language

| Field | Value |
| --- | --- |
| Category | Context |
| Priority | High |
| Status | Executed on Gemini, ChatGPT, Claude, and Perplexity |
| Products | Gemini, ChatGPT, Claude, Perplexity |

## Objective

Check that a fact stated in an earlier turn is still available in a later turn of the same chat.

## Prompts

Run this case once on each product. Start a new chat for each product. Send each turn below as its own message.

### Turn 1

```text
Remember this for the rest of this chat: my favorite programming language is Python. Reply with "Noted."
```

### Turn 2

```text
What is my favorite programming language?
```

## Preconditions

- Free tier of Gemini, ChatGPT, Claude, and Perplexity. Test each product in its own chat.
- A new conversation, with no earlier messages and no uploaded files.
- No custom instructions and no memory carried over from another test.
- The model label visible in the product is recorded before scoring.

## Steps

1. Open a new chat on the free tier of the product under test.
2. Record the model label shown in the interface and the date.
3. Send turn 1 and wait until the reply finishes.
4. Send turn 2 and wait until the reply finishes.
5. Record a condensed reading of the last reply, plus the chat URL, the model label, and the score.
6. Keep every turn of this case in the same chat. Do not start a new chat between turns.

## Ground Truth

Python.

## Expected result

The second answer is Python. The two prompts are sent as separate turns in one new chat.

## Scoring

- 2 — The second answer is Python.
- 1 — Python is given together with an extra language the user did not state.
- 0 — Another language is given, or the model says it was not told.
