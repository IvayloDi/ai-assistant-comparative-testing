# TC-015 — Release-note extraction

| Field | Value |
| --- | --- |
| Category | Context |
| Priority | High |
| Status | Executed on Gemini, ChatGPT, Claude, and Perplexity |
| Products | Gemini, ChatGPT, Claude, Perplexity |

## Objective

Check extraction of four specific facts from a passage supplied in the previous turn.

## Prompts

Run this case once on each product. Start a new chat for each product. Send each turn below as its own message.

### Turn 1

```text
Read and remember this release note. Do not summarize it yet.

On 14 March 2024, Northwind Analytics shipped build 4.2.7 of LedgerPilot to the Dublin office. The release owner is Maya Chen. The rollback code is R-19. Support hours are 08:00-16:00 UTC. The build must not be installed on the Oslo cluster.

Reply with "Noted."
```

### Turn 2

```text
From the release note I gave you, extract only these four fields: release owner, build number, rollback code, and the cluster where installation is forbidden.
```

## Preconditions

- Free tier of Gemini, ChatGPT, Claude, and Perplexity. Test each product in its own chat.
- A new conversation, with no earlier messages and no uploaded files.
- No custom instructions and no memory carried over from another test.
- The model label visible in the product is recorded before scoring.

## Steps

1. Open a new chat on the free tier of the product under test.
2. Record the model label shown in the interface and the date.
3. Send turn 1 and wait until the reply finishes.
4. Send turn 2 and wait until the reply finishes.
5. Record a condensed reading of the last reply, plus the chat URL, the model label, and the score.
6. Keep every turn of this case in the same chat. Do not start a new chat between turns.

## Ground Truth

Release owner Maya Chen. Build 4.2.7. Rollback code R-19. Forbidden cluster Oslo.

## Expected result

The second answer contains all four values and does not substitute Dublin for Oslo.

## Scoring

- 2 — All four values are correct.
- 1 — Three of the four values are correct.
- 0 — Two or fewer values are correct, or values that were not in the note are invented.
