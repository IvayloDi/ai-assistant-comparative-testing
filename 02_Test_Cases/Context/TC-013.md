# TC-013 — Topic switch

| Field | Value |
| --- | --- |
| Category | Context |
| Priority | High |
| Status | Executed on Gemini, ChatGPT, Claude, and Perplexity |
| Products | Gemini, ChatGPT, Claude, Perplexity |

## Objective

Check that the model follows a topic change and reports the latest topic.

## Prompts

Run this case once on each product. Start a new chat for each product. Send each turn below as its own message.

### Turn 1

```text
The topic is football. Who won the 2022 FIFA World Cup? Answer in one sentence.
```

### Turn 2

```text
Switch the topic to software testing. What does oracle mean in software testing? Answer in one sentence.
```

### Turn 3

```text
What is the current topic of this conversation? Answer with the topic only.
```

## Preconditions

- Free tier of Gemini, ChatGPT, Claude, and Perplexity. Test each product in its own chat.
- A new conversation, with no earlier messages and no uploaded files.
- No custom instructions and no memory carried over from another test.
- The model label visible in the product is recorded before scoring.

## Steps

1. Open a new chat on the free tier of the product under test.
2. Record the model label shown in the interface and the date.
3. Send turn 1 and wait until the reply finishes.
4. Send turn 2 and wait until the reply finishes.
5. Send turn 3 and wait until the reply finishes.
6. Record a condensed reading of the last reply, plus the chat URL, the model label, and the score.
7. Keep every turn of this case in the same chat. Do not start a new chat between turns.

## Ground Truth

Software testing.

## Expected result

The third answer is software testing. Football is not reported as the current topic.

## Scoring

- 2 — The third answer identifies software testing as the current topic.
- 1 — Both topics are mentioned, but software testing is identified as the latest one.
- 0 — Football is given as the current topic, or the answer is unrelated.
